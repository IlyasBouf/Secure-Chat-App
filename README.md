Secure Chat App is a secure messaging application focused on protecting user privacy through end-to-end encryption. It provides a simple web interface for registration, login, private conversations, and group chats, with user management, token-based sessions, bcrypt password hashing, and cryptographic mechanisms based on ECDH, HKDF, and AES-GCM to protect messages. The goal of this project is to demonstrate a modern chat architecture that combines WebSockets, authentication, and application-level security in a smooth and accessible user experience.
